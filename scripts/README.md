Build and deployment scripts use only Python 3, Node.js and the existing AWS CLI. AWS deployment always selects the `pinhaoyun` profile and Sydney region. Local environment files and deployment outputs are ignored by Git; no credentials belong in the app bundle.

`deploy-staging.mjs` packages the companion backend Lambda sources for the isolated core environment. `deploy-api.mjs` freezes a credential-free source snapshot, builds and smoke-tests the API-only container through CodeBuild, then manually deploys App Runner. It reads the existing ignored `infra/api.local.json` test allowlist; `--image-tag` can reuse a previously verified immutable image after a service configuration failure. Health success is required before it saves `infra/api-output.local.json`. Its failed-stack recovery refuses stacks that still contain resources.

`backup-integration-test.mjs` consumes two existing synthetic `ios-qa-…@example.invalid` fixture accounts. Default endpoint is the deployed isolated API; `TEST_API_BASE_URL=http://127.0.0.1:3000` checks the local counterpart. It needs the isolated localhost Web endpoint for Cookie compatibility. It uploads random valid PNGs, checks exact bytes/quota/ownership, deletion suppression, late-object cleanup, manual restoration, init replay, concurrent deduplication, completed-original expiry and cancellation. It retains one restored image as a QA fixture; all temporary test files are removed. Results are ignored in `infra/backup-proof.local.json`, explicitly marked as script evidence rather than physical Photos/background proof.

The core integration/erasure scripts create and destroy only guarded synthetic fixture accounts. They overwrite ignored fixture-state files, so preserve those files before a new regression cycle if another simulator uses the existing fixtures. Never use the tester's real email in erasure scripts.

For ongoing real-device tests, use the app's local diagnostics export and `docs/DEVICE-ACCEPTANCE.md`; do not treat scripted dates or simulated background callbacks as three days of actual use.
