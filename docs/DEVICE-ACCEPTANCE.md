# 0.2 真机验收记录

本期只使用隔离测试环境。App 版本 0.2.0（3），最低 iOS 17；已在 iPhone 12 / iOS 27.2 安装。构建 2 通过 15 项 XCTest（13 项本地回归、2 项生成图片的云端传输检查）；构建 3 的 13 项本地检查再次通过，包含密码确认规则，2 项云端检查未重复启用。这些检查不等于真实相册、iCloud 或后台调度验收。

## 首次试用

1. 使用自己的隔离测试账号登录，阅读并明确确认草稿条款。测试账号与生产 Web 账号的密码、数据各自独立。可在 App 内自行重置测试密码，无需向开发者发送密码。
2. 手动上传少量普通照片、HEIC、视频、真实 Live Photo 以及一份 iCloud 原片。确认上传完成、原件可预览/保存、Live Photo 动态可播放；检查原件字节与配对资源完整性。录入素材类型和结果，不记录私人照片内容。
3. 前往“我的 → 自动备份”。首次测试建议在系统权限中只授权少量测试照片，选择“全部可访问照片”；需要普通视频时单独开启视频。确认授权范围后开启。默认关闭、仅新增、视频关闭、仅 Wi‑Fi、不限时段。
4. 等“传输”显示完成，再检查图库。重复检查/重开 App，确认没有重复云端副本或重复配额。测试结束可切回“仅新增”，只处理之后新增或新授权的项目。

有限权限不会自动获得每张新拍照片，需要把新照片加入授权选择，或自行改为完全访问。手机删除不影响云端；云端删除会阻止自动回传，手动选择仍可重新上传。

重设密码采用三页：邮箱 → 6 位验证码 → 新密码及再次输入。两次一致且满足规则才能保存。按已确认的 Cognito 方案，验证码在保存时由服务器实际校验；错误/过期会返回验证码页，不提前提示验证成功。输入框与流程在小屏中文模拟器已检查；实际密码由本人输入。
